# Neon Runner

Tarayıcıda çalışan, bilgisayar ve telefon için dokunmatik kontrollü 2D arcade oyunu.

## Bilgisayarda çalıştırma

1. Depodaki **Code → Download ZIP** seçeneğiyle dosyaları indirip ZIP'i aç.
2. `index.html` dosyasını tarayıcıda aç.
3. Başlat'a bas. Hareket için WASD veya ok tuşlarını kullan.

## Telefonda oynama

1. Oyunu GitHub Pages ile yayınlayın (aşağıdaki adımlar) ya da yerel dosyaları bir web sunucusunda barındırın.
2. Telefonda site bağlantısını açıp **Başlat**'a dokunun.
3. Ekrandaki yön tuşlarına basılı tutarak karakteri hareket ettirin.

## GitHub Pages ile yayınlama

1. Depoda **Settings → Pages** bölümünü açın.
2. **Deploy from a branch** seçin.
3. Branch `main`, klasör `/(root)` seçip **Save**'e basın.
4. Pages bölümünde verilen bağlantıdan oyunu açın.
